# Phase 03 · Feasibility on the pinned renderer

**Phase 03 outcome.** The baseline assessment below was performed before implementation. The delivered build enables Iced’s cross-platform `image-without-codecs` feature, uses raw offline plates, custom focus traversal, clipped preview geometry, scheduled frame observation during transitions, and native window resizing. SVG, Canvas and advanced widgets remain disabled. The menu expands inline and Profile opens Accounts. See [implemented behavior](UI-DESIGN.md) and [performance validation](PERFORMANCE.md). The capability matrix describes the original baseline and options considered. Cargo.lock gained 33 resolved package entries with the feature change. No previous package version changed. The host active dependency graph excludes iced_wgpu. Raw RGBA avoids runtime file decoding. Three selectable families have stable handles for their original card and preblurred background. Only the backgrounds involved in a transition are drawn. The fourth family is a lazy fallback.

**Research baseline.** The manifest pins iced 0.14.0, disables defaults, and selects tiny-skia, thread-pool, X11 and Wayland. The lock resolves iced_widget 0.14.2, iced_runtime 0.14.0 and iced_tiny_skia 0.14.1. The Linux window backends are features of a cross-platform build; Windows keeps its native window. Inspected the versioned documentation and the Cargo registry sources corresponding to the lock. Rustdoc lists optional APIs from an all-features build. A documented type can therefore be unavailable in Averion. No compile spike or interactive test was performed. | Home version preview | Direct | One Iced button encloses a stack of artwork and caption. The whole card shares pointer bounds and a logical keyboard focus target. Activation takes the existing Versions route. |

## Rendering cost and later verification

- **Memory estimate.** One 1600 × 900 RGBA buffer holds 5.49 MiB. Two plus three 640 × 360 thumbnails hold about 13.62 MiB of raw pixels. Actual peak also includes decoder scratch, renderer caches, framebuffer, scaled surfaces and text. Encoded file-size targets do not bound these allocations. Keep compressed assets local and release unused handles. Measure cache eviction in the renderer rather than assuming a dropped view frees memory immediately.
- **Work admission.** Decode off the UI path once per requested key where the approved image path permits. Bound simultaneous decoding, discard stale completions and avoid a queue of every transient selection. Inspect first draw for synchronous upload/decode. Hardware acceleration and a high frame rate are not prerequisites for correct input. If fading two full images spikes CPU or memory, switch one prepared background and retain the small selection transition.
- **Measurement plan.** Compare the current release shell and future release build on 2 GB total-RAM systems on Linux and Windows. Record cold start to usable interaction, steady idle CPU and resident/private memory, peak while rapidly selecting releases, time to respond to a key, and frame times during resize. Include high DPI, maximized and minimized windows and repeated entry/exit. Verify no animation subscription or image work continues after settling. Report OS, display, scale, renderer, sample count, cache state and system memory pressure. No Phase 03 performance claim or hardware measurement is made here. [Existing performance protocol](PERFORMANCE.md)
- **Implementation review order.** First validate keyboard reachability, narrowing and popover dismissal with solid surfaces. Then test a rights-cleared image pair, decoder footprint, crop/clip interaction, cache bounds and a static swap. Compare short fades with static swaps last. Preserve existing F1 behavior. These are separate future assignments.

### Glass panel regression check

In the Linux X11 release at 640 × 440, 1120 × 720 and 1440 × 900, repeated pointer movement between the navigation and profile changed only the hovered control's bounds in the final navigation capture. Moving onto the artwork or outside the controls restored the entire bar pixel-for-pixel at each size. On the tundra scene, the muted profile text color against the brightest sampled background in the adjacent panel gutter measured 5.60–5.62:1. This checks the sampled render at default scale. Windows, assistive technology and 2 GB hardware validation remain open.
