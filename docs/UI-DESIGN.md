# Native desktop UI

Phase 03 opens Home in a decorated, resizable Iced window at 1120 × 720 logical pixels. The minimum client area is 640 × 440. The selected local sample controls both its landscape card and the soft, dark background. The bundled update covers and original icons work offline. The renderer remains tiny-skia. [Artwork credits](../assets/version-covers/README.md) · [Design research](DESIGN-RESEARCH.md)

The floating top bar uses a translucent slate gradient and a fine rim. All seven destinations share the selected version’s preblurred landscape. Secondary pages draw it at 70% opacity over the dark canvas to keep headings legible. The launcher prepares one physical-size background on its worker pool and reuses it until the selected family, window size or display scale changes. While it prepares a new cover at the same size, it draws the previous cached image. At startup and during resizing it can draw the bundled source. The cache is limited to a 4K pixel budget. The bar opens Home, Versions, Mods, Accounts, Settings, News and Friends. Below 1060 logical pixels, Home, the menu trigger and the profile stay in the first row. The expandable menu lists the other destinations. The profile opens Accounts. The body scrolls independently of navigation. On Home, compact mode reduces the card height and stacks the two news sources.

- Click anywhere on the Home artwork or its caption, or focus the card and press Enter or Space, to open Versions. The top Versions entry opens the same gallery with focus on the current card. The gallery groups 40 stable Java releases from 1.16 through 26.3 into nine family cards. Open a card to see its releases in a dialog. Tab cycles within the dialog, Escape returns focus to the family card, and choosing a release returns to Home with the exact version number and the family cover. Left and Right leave the selection unchanged. The gallery has fixed local content and never enters a network loading state.
- Tab and Shift+Tab move the visible focus outline. Enter and Space activate the focused control. Escape dismisses the compact menu. The Minecraft-font `DOWNLOAD` button starts Mojang metadata resolution for the selected release.
- Home names the release during metadata resolution. During `INSTALLING`, the progress bar sits directly below the main button. The status reports game and Java download progress, names the active file, and shows extraction progress for natives and compressed Java files. Cancel and Retry are keyboard-accessible. The progress bar is hidden when idle or after a failure. Success confirms the game files and compatible Java major.
- Startup details (F1) toggles the existing version, interface and renderer disclosure. F1 also returns to Home when invoked on another page.
- Settings changes Reduced motion for the current process. The navigation bar edge animates for up to 180 ms. A new version family replaces the previous background in a single step when its cached image is ready. Buttons have immediate hover/press feedback. OS reduced-motion detection and persistent settings are deferred.
- Accounts saves an offline Minecraft username. Home offers Download for releases without an installation record and Play for installed releases. News provides an empty state. Mods and Friends identify planned features.

The palette and original outline symbols are shared across routes. Keyboard focus is explicitly modeled because stock Iced 0.14 buttons handle pointer/touch activation. Screen-reader semantics remain a framework limitation and require platform testing. [Implementation feasibility](ICED-DESIGN-FEASIBILITY.md) · [Full design direction](UI-UX-SPECIFICATION.md)
